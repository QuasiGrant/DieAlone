Conventions set in Locations.md:
- 35 m site / 40 m camp radius is horizontal; elevated sources use slant max distance (vane 66 m, stack 41 m).
- Fire is a proxy emitter row at the cliff (x 0), reach stepped by WARD band (140/190/300/420 m); per-zone fire offsets; three west glimpse volumes.
- Cave: chant outside only (supersedes DN 8 thump idea, DECISIONS 2026-09-29); inside, progress from floor height drives chant to bass (lowpassed music) to full mix.
