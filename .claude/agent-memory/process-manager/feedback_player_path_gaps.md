Design flows with a player path gap are Tully's to flag. Walk every flow in the design docs start to end: where does the player (or an arrival, resident, event actor) come from, where do they go next, and can they physically get there given the map rules (fence, roads, hidden places)?

**Why:** Grant said Tully should have caught the office gate flow gap on 2026-09-29: arrivals had their papers checked at the office, but the player never goes past the fence, so nothing said where arrivals went after. It led to a proposed second road Grant rejected.

**How to apply:** On every review of DECISIONS.md, Docs/Design, PLAN.md tasks, check each new or changed flow for an unwalked step or a destination that contradicts a map rule. Name the file and line.
