Ask Marlow or Rook for Terrain.SampleHeight along any new line before fixing grades or structure heights.

**Why:** WardPath draft 1 (2026-10-01) put a stair "on the slope" that actually stood on a flat bench, making it a 15 m timber tower, and drew a closure rim that left a 10 m gap. Marlow blocked both. Also: the mover fix a23ff06 (2026-09-30) already stops hops on ground over 45 degrees; check PLAN Rules before citing older Valley.md mover notes.

**How to apply:** For any layout change, list the points needing samples in the doc or ask first; check every fall from a structure lands on open ground that leads back (no soft locks); closures must run continuous from face to face.
