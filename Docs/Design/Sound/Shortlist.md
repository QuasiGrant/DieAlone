**DRAFT, 2026-09-29, Hollis. Nothing here is decided.** For Grant to download himself. Milestone 9 (PLAN.md): footsteps, the fire pit loop, one ambience bed per zone. Surfaces: AudioTuning.md 3.1. ## How to use this list

1. Freesound needs a free account to download. Download the original file (the "Download" button), not the preview.
2. **Licence check on every page before download.** Every Freesound link below came from a search with the licence filter set to Creative Commons 0 on 2026-09-29. I did not open each page, so each is **unverified** until the page itself shows "Creative Commons 0" (right-hand box). If it shows anything else, skip it. CC-BY 4.0 is allowed with credit; CC-BY-SA and any NC licence are not (DECISIONS 2026-09-29).
3. Lengths and file formats were not shown in the search results: **unverified**. Take .wav or .aif where offered. .flac, .m4a and .opus need converting to .wav first (Sourcing.md 3; Unity import of these unverified).
4. Save into the folder given, keeping the Freesound ID at the start of the file name (for example `843928_GAVDOS_Dry_Wind.wav`). Cutting, looping and renaming to the final name is a separate edit step (who does it: open). Each file gets a row in Assets/SOURCES.md before it is committed (Sourcing.md 2a).
5. Envato Elements: search terms only; I cannot see Grant's account. Envato files go in git-ignored Assets/Audio/_Envato with the same subfolders, and the licence certificate in Docs/Private/Licences (Sourcing.md 1a).
6. Pick one candidate per row and listen for what the row says to avoid. Two or three are given so there is a fallback.
