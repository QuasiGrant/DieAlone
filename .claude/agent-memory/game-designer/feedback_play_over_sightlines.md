Map design optimizes, in order: the loop plays (each trip has a reason and is worth taking), readability (paths read as paths, stops visible), the fantasy (dense giant forest, Ward reveal), pacing and variety, then hard constraints checked once (Ward/fire hidden day 1, cave hidden). "Tower sees every place" is a loose check, not a margin table.

**Why:** Grant walked the valley build 2026-09-30 and was very unhappy: few trees, paths look like grass, pointless invisible walls, uniform Ward climb, empty north. Valley.md went seven revisions mostly on sightline margins (a cap rock added to block one ray) with no line on what the player does.

**How to apply:** Every map doc opens with a per-leg player section. No revision that only moves margins. Before signing a build, read player-eye screenshots along each route and a playability list (paths, stops, warps, dev menu findable). Give Grant a rough walkable version early.
